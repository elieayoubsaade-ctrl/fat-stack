# Memory

- The game is designed for a landscape 16:9 event TV with left/right joystick input and one red start button.
- Keyboard fallback is Left/Right arrows and Space/Enter.
- The user-approved visual system is cream deli paper, purple comic bursts, red actions, black hand-drawn outlines, tiger-crunch bread, and actual Fatsandwich characters.
- The game is original: it must not use Disney, Lilo & Stitch, Experiment 625/Reuben, copied assets, or copied UI.
