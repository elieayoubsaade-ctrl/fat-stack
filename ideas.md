# Fatsandwich Super Stack — Game Visual Direction

## Three Directions Considered

| Theme Name | Very Brief Intro | Probability |
|---|---|---:|
| **Deli Receipt Riot** | A paper-receipt arcade with red order tickets, stamp marks, and a score that feels printed by a loud deli till. | 0.08 |
| **Purple Lunchbox League** | A more collectible, toy-like game world that treats the Super Stack as a schoolyard trophy. | 0.04 |
| **Comic Counter Carnival** | A high-energy sandwich-counter game using comic bursts, bold ingredient cut-outs, and the Fatsandwich character cast as active hosts. | 0.09 |

## Chosen Direction — Comic Counter Carnival

### Design Movement

Use **1990s sticker-book illustration, American deli ephemera, and screen-printed comic graphics**. The game should feel like a physical Fatsandwich activation has been flattened into a sharp, readable arcade interface.

### Core Principles

1. Keep the play lane exceptionally clear; the game must work from several metres away in an event queue.
2. Let the Fatsandwich characters perform actual interface roles—player, scorekeeper, host, judge—not merely fill unused space.
3. Pair expressive hand-drawn outlines with disciplined event-screen hierarchy, large controls, and limited visual noise.
4. Make every score, catch, fumble, and completed stack feel tactile through quick motion, impact bursts, and physical deli-material metaphors.

### Color Philosophy

Anchor every screen in **cream deli paper**, so purple, red, and black feel printed rather than digitally glowing. Purple owns the game’s identity and key frames; vivid red signals actions, danger, score changes, and prize moments; black keeps both characters and game data sharp. Supporting ingredient colors are functional cues, not decorative confetti.

### Layout Paradigm

Build each game view like a **counter ticket spread**: a tall central food-prep lane, a score zone to the left, an order ticket and combo column to the right, and a broad bottom stage for the player character and its growing Super Stack. Avoid a centered-card landing page; the game screen is an asymmetric live counter.

### Signature Elements

1. Jagged purple score bursts with red bubble lettering and black shadow lines.
2. White deli-order tickets with torn/pinked edges for objective, high-score, and result information.
3. A tiger-crunch bread texture as the player silhouette, finished with big, expressive Fatsandwich eyes.

### Interaction Philosophy

The game must take under five seconds to understand. The large arcade joystick moves left/right, the red button advances screens, and the screen rewards successful catches with a short physical “stack snap.” Movement stays smooth; menu input stays instant.

### Animation

Ingredients drop with light wobble and acceleration, then land with a 100–160ms squash. Combo bursts punch in at 0.95 scale and settle. Fumbles use a short red stamp shake. The completed sandwich receives one rare celebratory bounce and a rising paper-ticket score count. All nonessential movement respects reduced-motion preferences.

### Typography System

Use a thick, rounded comic display face for titles and scores, paired with a compact handwritten/marker-style uppercase face for tickets and small instructions. Main UI numbers remain high contrast and large. Never use Inter. All component-level styling must retain this pairing.

### Brand Essence

**A playable deli spectacle that turns the Fatsandwich Super Stack into the event’s most competitive sandwich.**

Personality: **cheeky, generous, kinetic**.

### Brand Voice

Headlines are direct, playful, and rewarding. Microcopy never overexplains.

> “CATCH THE GOOD STUFF.”

> “STACK IT. WIN IT.”

### Wordmark & Logo

Keep the existing FAT SANDWICH red comic wordmark inside its purple burst as the master mark. Create a supporting **Super Stack icon**: a no-text stacked tiger-crunch sandwich with a toothpick flag, usable as a score chip, favicon, and prize badge.

### Signature Brand Color

**Super Stack Purple — `#7B5EA7`**.

## Style Decisions

- Use no Disney, Lilo & Stitch, Experiment 625/Reuben, or copied game artwork, names, music, or UI.
- Use the Fatsandwich ingredient/character world as the complete source of game personality.
- Use a wide 16:9, landscape-first interface for the event TV; retain keyboard fallback controls.
