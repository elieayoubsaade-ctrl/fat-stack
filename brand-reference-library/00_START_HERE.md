# Fatsandwich Design Asset Library

This is the complete organized library of **every Fatsandwich design asset supplied in this project**, together with the working brand guidance created from those assets. The package preserves original uploads in their original filenames and also provides production-friendly copies grouped by practical use.

> **Use the organized folders for everyday design work.** Use `99_Original_User_Uploads` whenever the untouched original upload is required.

## Core Visual System

Fatsandwich is a **character-led, pop-art-inspired sandwich brand**. It is energetic, hand-drawn, playful, and a little irreverent; avoid polished corporate minimalism. The hero identity is a red rounded comic wordmark inside an irregular purple comic burst with a thick black outline and shadow.

| Brand role | Color | Working hex |
|---|---|---|
| **Primary purple** | The hero burst, large brand fields, and brand anchor | `#7B5EA7` |
| **Primary red** | Wordmark, high-energy display text, and key graphic accents | `#E8191A` |
| **Outline black** | Character outlines, logo outlines, comic shadows, and contrast | `#000000` |
| **White** | Negative space, deli paper, packaging base, and clean layouts | `#FFFFFF` |
| **Supporting mint** | Captain Tuna world | `#A8E6C8` |
| **Supporting orange** | Runny Sunny and warm action accents | `#F26522` |
| **Supporting sky blue** | Chop-Chop and Egghead worlds | `#4DA6E8` |
| **Supporting yellow** | Impact bursts and small highlight moments | `#F5D020` |

These values are practical working approximations based on the supplied visual assets. Confirm final print values with the original identity designer before fabrication, large-format print, or color-critical production.

## Brand Usage Principles

Use the purple burst/red wordmark combination as the primary brand signature. Use the hand-drawn starburst pattern as a background texture, especially on white deli-paper style layouts. Keep character artwork raw and slightly imperfect; do not redraw it in a clean corporate illustration style. For food photography, retain the consistent bright white studio background, tiger/Dutch-crunch roll, generous visible fillings, three-quarter front angle, and restrained soft shadow.

Do not use the logo, character system, and dense burst pattern all at maximum intensity in one composition. Choose a lead visual and let supporting elements stay secondary.

## Character Files

The full character artwork folder contains the existing artboards. The transparent cut-out folder contains PNG files intended for placing characters over packaging, posters, social graphics, menus, or event environments. The original ZIP is also retained for source preservation.

## Package Scope

The asset library intentionally contains both the design-ready library and every original user upload provided in this project. The `04_Product_and_Packaging_References` and `05_Event_Stand_and_Game_Inspiration` folders are provided as creative reference material; they should not be treated as final Fatsandwich master artwork unless separately approved.

For a visual index of each asset, use the filenames and `ASSET_MANIFEST.csv` to quickly find the appropriate source. Keep all files together when moving the package so the documentation paths remain valid.
