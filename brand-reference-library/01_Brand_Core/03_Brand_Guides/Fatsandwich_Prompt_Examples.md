## Editing Existing Food Photos

When asked to add brand elements to an existing food photo:
1. Keep the food photo clean and unaltered as the hero
2. Add the purple burst logo as an overlay (corner or centered above/below)
3. Optionally add a starburst doodle pattern as a border or background strip
4. Add character illustration as a small accent element if relevant
5. Keep text minimal — only the sandwich name and/or price if needed
